# speedtest

Консольный скрипт на Node.js для замера скорости скачивания.

Скрипт делает к указанному адресу 10 GET-запросов **последовательно**, каждый раз дожидается полного получения тела ответа, затем выводит:

- время и размер каждого запроса;
- среднее время запроса;
- общий объём скачанных данных;
- скорость скачивания.

## Требования

Node.js **18+** (используется встроенный `fetch`). Внешних зависимостей нет — `npm install` не нужен.

## Запуск

```bash
git clone https://github.com/devdevdenis/speedtest.git
cd speedtest
node speedtest.js <url>
```

Примеры:

```bash
# 10 запросов (по умолчанию)
node speedtest.js https://proof.ovh.net/files/10Mb.dat

# другое число запросов
node speedtest.js https://proof.ovh.net/files/10Mb.dat -n 5

# через npm
npm start -- https://proof.ovh.net/files/10Mb.dat
```

Пример вывода:

```
Адрес: https://proof.ovh.net/files/10Mb.dat
Запросов: 10 (последовательно)

# 1  1.412 с    1.25 МБ  7.43 Мбит/с
...
#10  1.287 с    1.25 МБ  8.15 Мбит/с

— Итог —
Успешных запросов:       10 из 10
Среднее время запроса:   1.334 с
Всего скачано:           12.50 МБ (13107200 байт)
Скорость скачивания:     7.86 Мбит/с (0.94 МБ/с)
```

## Параметры

| Аргумент            | Описание                                  | По умолчанию |
|---------------------|-------------------------------------------|--------------|
| `<url>`             | Адрес (http/https), к которому стучаться  | —            |
| `-n`, `--count`     | Количество последовательных запросов      | `10`         |
| `-h`, `--help`      | Справка                                   |              |

## Единицы измерения

- **Время** — секунды (`с`).
- **Объём** — двоичные единицы: 1 КБ = 1024 байта, 1 МБ = 1024² байт. Дополнительно выводится точное число байт.
- **Скорость** — основная единица **Мбит/с** (мегабиты в секунду, 1 Мбит = 10⁶ бит), как у провайдеров и speedtest.net. В скобках — **МБ/с** (мебибайты в секунду), как показывают браузеры и менеджеры загрузок.

## Как считается

- Время запроса — от отправки запроса до получения последнего байта тела (включает DNS, установку соединения, TTFB и скачивание).
- Скорость = суммарный объём ÷ суммарное время всех успешных запросов.
- Тело читается потоком и не хранится в памяти, поэтому можно качать большие файлы.
- Отправляются заголовки `Cache-Control: no-cache` и `Accept-Encoding: identity`, чтобы не попадать в кеш и считать реально переданные байты, а не распакованные.
- Неуспешные запросы (сетевые ошибки, HTTP-статус не 2xx) выводятся в консоль и не учитываются в итоге.

## Коды выхода

| Код | Значение                                   |
|-----|--------------------------------------------|
| `0` | Все запросы успешны                        |
| `1` | Ошибка аргументов                          |
| `2` | Ни один запрос не завершился успешно       |
| `3` | Часть запросов завершилась с ошибкой       |
